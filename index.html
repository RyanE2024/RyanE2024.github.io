Professional Introduction

Professional Self-Assessment

Throughout my Bachelor of Science in Computer Science program at Southern New Hampshire University, I have developed a much better understanding of what it takes to design, develop, and maintain software. When I first started the program, my focus was primarily on learning how to write code and understanding how different programming languages worked. As I progressed through my courses, I began to understand that computer science involves much more than programming. It requires problem-solving, communication, planning, testing, security awareness, and the ability to make decisions that balance technical requirements with real-world needs.

My coursework introduced me to several areas of computer science, including mobile application development, full-stack web development, databases, software testing, networking, and artificial intelligence. Through these experiences, I became more comfortable working with Java, Python, JavaScript, SQL, and other development tools. I also learned how important it is to understand the overall structure of an application instead of focusing only on individual pieces of code.

One project that helped me develop these skills was my full-stack web application for Travlr Getaways. This project involved building customer-facing pages, creating administrative functionality using Angular, connecting the application to MongoDB, and implementing authentication. It helped me understand how frontend development, backend services, APIs, databases, and security controls work together to create a functional application. I also gained experience troubleshooting integration problems and testing whether information was being transferred correctly between components.

My coursework also helped me recognize the importance of communicating technical information to different audiences. Whether documenting a software project, explaining a design decision, or describing an issue that needs to be resolved, developers need to communicate clearly. Collaborative environments depend on being able to explain problems, consider feedback, and support decisions using evidence. I have practiced these skills through project documentation, course discussions, technical reflections, and explaining the reasoning behind the improvements I make.

My experience with algorithms and data structures has taught me to think more carefully about efficiency and how data is processed. Rather than simply writing code that produces a result, I have learned to consider how an algorithm performs, how information should be organized, and whether a different approach would be more appropriate. Database development has reinforced these lessons by showing me the importance of reliable data storage, relationships between records, and maintaining data integrity.

Cybersecurity has become one of my strongest professional interests. Throughout my program, I have learned that security should be considered during the design process rather than added only after development is complete. Authentication, input validation, access control, secure data handling, and the ability to review previous activity are all important parts of building trustworthy applications. These interests influenced the direction of my capstone project and my decision to pursue a master's degree in Cybersecurity with Information Technology Management.

My CS 499 capstone allowed me to bring together several areas of my education into one project. I selected an Android inventory application I previously developed and enhanced it into Sentinel, an asset security management application. This project demonstrates how software engineering, algorithmic problem-solving, database development, and security awareness can work together to address a practical organizational need.

Completing this project strengthened my ability to work through problems independently, troubleshoot unexpected errors, and improve existing software without losing important functionality. It also helped me recognize areas where I want to continue growing, particularly in cybersecurity practices, enterprise systems, and information technology management. My goal is to begin my career in information technology, continue developing practical experience, and eventually move into a more specialized cybersecurity role.

This portfolio represents the technical skills and professional mindset I have developed throughout my degree program. Featured Capstone Project

Sentinel: Asset Security Management

Sentinel is an Android application developed in Java with SQLite database integration. It began as a basic inventory management application created during CS 360 Mobile Architecture and Programming.

For my CS 499 capstone, I enhanced the original application into a security-focused asset management system. Sentinel allows users to register assets, evaluate their security risk, document security events, review historical risk assessments, and examine audit records.

Software Design

Expanded application functionality, improved asset management, and added security-focused screens.

Algorithms

Developed a risk scoring system and prioritized assets based on calculated security risk.

Databases

Expanded SQLite to maintain risk history, security events, and audit logs.

Enhancement One

Software Design and Engineering

My first enhancement focused on transforming the original inventory application into a more structured security asset management system. I expanded the application with an Asset model, asset registration features, security-focused navigation, and additional screens that made the application more useful.

Skills Demonstrated

  • Java and Android application development
  • Object-oriented programming and data modeling
  • User interface development and navigation
  • Software troubleshooting and testing
  • Maintaining existing functionality during enhancements

This enhancement demonstrated my ability to evaluate existing software, identify opportunities for improvement, and implement changes that support a more specialized purpose.

Enhancement Two

Algorithms and Data Structures

My second enhancement focused on developing the Adaptive Asset Risk Engine. This feature evaluates registered assets using security-related attributes such as criticality, patch status, exposure, and recorded incident counts.

Each asset receives a risk score and classification. The dashboard prioritizes assets by calculated risk, allowing users to identify which assets may require attention first.

Skills Demonstrated

  • Algorithm design and implementation
  • Risk scoring and classification
  • Sorting assets by risk priority
  • Linear search for highest-risk identification
  • Evaluating algorithm efficiency and trade-offs

This enhancement showed me how algorithms can be applied to practical cybersecurity problems instead of only being used in classroom exercises.

Enhancement Three

Database Development

My final enhancement expanded the application's SQLite database to support historical security information. The original inventory application primarily stored current asset information. Sentinel now maintains additional records that allow users to review previous activity.

Database Features

  • Risk History: Records previous asset risk assessments and classifications.
  • Security Events: Stores documented incidents with event types, severity levels, and descriptions.
  • Audit Logs: Records asset creation, updates, and deletions.
  • Audit Retention: Preserves audit records even after an asset is deleted.

I tested these features in the Android emulator. Security events remained available after reopening the screen, and audit logs successfully recorded asset creation, modification, and deletion. Audit records also remained accessible after the associated asset was removed.

This enhancement strengthened my understanding of relational database design, SQLite integration, data persistence, and the importance of preserving security-related information.
